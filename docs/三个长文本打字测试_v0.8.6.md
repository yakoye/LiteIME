# 三个长文本打字测试（v0.8.6）

v0.8.6 继续执行三组真实文本逐键回放、段落输入、结构化语料和逐键延迟门禁，结果与 v0.8.5 一致，无回归。

本版只在一条**此前会丢弃符号**的边界上有改动：候选逐段落定走不到提交时。正常输入不经过它，因此语料回放结果预期逐字节不变。

## 本版必须复验的项

- **回放输出与 v0.8.5 逐字节一致。** 本版改的是一条异常路径，正常路径未动。出现任何差异都要查清原因。
- **标点数量守恒。** 语料里每一个标点都应出现在输出中。这条修复的本质就是「按下去的符号必须到达文档」，逐键回放正好能核对这一点——统计输入的标点键次数与输出中的标点个数是否相等。
- **延迟门禁未退化。** 改动只发生在原本就要返回的那个分支里，正常路径不多做任何事。
- **v0.8.4 / v0.8.5 的修复仍然有效**：横杠可输入、句号的形态由提交文本决定。

## 真实应用手工测试

必须使用验证记录中的同一 build ID。**每个受测程序都要完全退出重开**——输入法组件是 DLL。

1. **中文输入不受影响**（最重要）：打 `wo` 选「我」再按句号，应直接得 `我。`；打一段完整中文确认句号行为与以往一致。
2. **符号不丢失**：连续输入若干「拼音 + 标点」的组合，每一个标点都应出现在文档里，不得有按了键却什么都没出现的情况。
3. **无候选的拉丁输入**：打 `geek` 再按句号得 `geek.`，再按一次得 `geek.。`。
4. **数字后的句号**：打 `0.8.1`，应逐字符如实输出。
5. **中文文本后的句号**：已上屏的中文后按句号，直接得 `。`。
6. **横杠**：中文模式打 `apple-book`，横杠正常落下。
7. **翻页未被破坏**：出候选后按 `=` 展开，再按 `-` 应往回翻一行。
8. **升级不中断已开程序**：装上本版后**不重启**任何已打开的程序，在其中继续打字，应正常工作。
