# PiInput v0.8.6 版本说明

本版修一个会让按键无声消失的缺陷。

## 标点符号有时会被丢掉

在合成串里打标点，输入法会先把剩下的音节逐段落定，好让符号和文字在同一次编辑中一起上屏。

这个逐段落定有可能**走不到头**：候选只能覆盖输入的前缀，而剩下的部分又没有候选可选。此前遇到这种情况，循环停下来之后那个符号**被整个丢掉**——你按了键，屏幕上什么都没多出来，也没有任何提示。

标点是明确的合成边界，解析停在半路不是不结束的理由。现在会把**已经落定的部分连同剩余输入一起上屏**，符号跟在后面。

## 一处容易写错的地方

修的时候不能拿「当前原始输入」去提交：分段选择状态下它只剩**未处理的拼音**，已经落定的中文在另一个字段里，那样会把它丢掉——用一个丢字的写法去修一个丢符号的缺陷，得不偿失。

整体上屏该写出的文本因此抽成了一处定义，快照和这条边界处理共用它。

## 怎么发现的

写 v0.8.5 的测试时撞到的：测试词库里 `geek` 恰好有部分候选、消费不完四个字母，返回的结果是「未提交、文本为空」。真实词库里 `geek` 没有候选，走的是另一条路，所以日常不容易遇到；但只要出现「候选只覆盖前缀且后续无候选」的输入就会复现。
