# 三个长文本打字测试（v0.8.5）

v0.8.5 继续执行三组真实文本逐键回放、段落输入、结构化语料和逐键延迟门禁。

本版改的是句号在**合成串上屏时**取什么形态，语料回放会受影响：以拉丁字母或数字结尾的合成串，其后的第一个句号现在是 ASCII。与 v0.8.4 的差异应当只出现在这类位置。

## 本版必须复验的项

- **中文候选后的句号逐字节不变。** 这是最重要的一条：拼音上屏为中文时，句号必须仍是 `。`。语料里绝大多数句号属于这一类，出现任何差异都说明改坏了正常中文输入。
- **差异只出现在原样上屏的拉丁输入之后。** 逐条核对回放输出与 v0.8.4 的差异，每一处的前一个字符都应当是 ASCII 字母或数字，且那段文本是原样上屏的输入而非中文候选。
- **延迟门禁未退化。** 判定只多了一次「取最后一个字节并分类」，没有新增查询或往返。
- **v0.8.4 的两条修复仍然有效**：横杠可输入、已上屏字母后的句号规则不变。

## 真实应用手工测试

必须使用验证记录中的同一 build ID。**每个受测程序都要完全退出重开**——输入法组件是 DLL。

1. **中文输入不受影响**（最重要）：打 `wo` 选「我」再按句号，应直接得 `我。`；打一段完整句子确认句号行为与以往一致。
2. **无候选的拉丁输入**：打 `geek` 再按句号得 `geek.`，再按一次得 `geek.。`。
3. **数字后的句号**：打 `0.8.1`，应逐字符如实输出。
4. **已上屏文本后的句号**：先上屏一个英文词，再单独按句号，得 `.`；再按一次得 `。`。
5. **中文文本后的句号**：已上屏的中文后按句号，直接得 `。`。
6. **冒号同理**：`http` 后第一次得 `:`；`注意` 后直接得 `：`。
7. **横杠**：中文模式打 `apple-book`，横杠正常落下。
8. **翻页未被破坏**：出候选后按 `=` 展开，再按 `-` 应往回翻一行。
