# PiInput v0.8.4 版本说明

本版修的是两个标点键打不出它们本该打出的字符。

## 横杠打不出来

中文模式下打 `apple-book`，横杠没反应。`in-to` 也一样，英文模式下同样如此。

横杠的另一个职责是**往回翻候选行**，而它在有合成串时被无条件当成翻页。但列表还是刚打开的那一行时**根本没有上一行可翻** —— Host 收到之后消费掉、什么都不做，横杠就成了死键。

这个"消费即止"本身是对的：有人正在浏览候选、翻过了头，不该把候选从屏幕上带走。错在它没有区分"正在浏览候选"和"正在打一个词"。

**展开状态就是这个区分**：没往下翻过，就谈不上往回翻。现在横杠只在列表展开时翻页，其余时候就是横杠。`=` 键不变 —— 从单行状态翻页正是它的用途，把列表打开。

## 数字后的句号规则现在也管字母

`0.8.1` 一直是对的，而 `apple.txt` 会变成 `apple。txt`，除非切到英文模式，否则打不出 ASCII 句点。

两键规则原本只认数字。现在数字和字母一视同仁：

| 输入 | 第一次按 `。` | 再按一次 |
| --- | --- | --- |
| `0.8` | `.` | `。` |
| `apple` | `.` | `。` |
| `这句话结束了` | `。` | —— |

**中文文本完全不受影响** —— 它最后一个字节不是 ASCII，走的还是原来的路。

代价是以英文单词结尾的中文句子，句号要按两次。这和数字那条是同一笔交易（`第1。` 本来就要按两次）。

冒号跟着一起改了，因为它本来就被要求"跟句号一样"：`http:` 现在第一次给 ASCII 冒号，`注意：` 不受影响。
